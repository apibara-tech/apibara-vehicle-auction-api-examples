## API name

Apibara Vehicle Auction Data API

## Short description

Structured Copart and IAAI vehicle auction API for VIN records, lot details, photos, prices, auction status, sale history, filters, locations and shipping prices.

## Long description

Apibara Vehicle Auction Data API gives developers structured JSON access to supported Copart and IAAI auction data. It can be used to build vehicle auction marketplaces, VIN auction history tools, dealer dashboards, export platforms, CRM enrichment workflows, shipping calculators, WordPress auction websites and AI agents that need reliable vehicle auction data.

The API supports vehicle search, VIN and lot details, auction photos, prices, sale history, related vehicles, filter metadata, auction locations and auction-to-port shipping estimates. Authentication uses the `X-API-Key` header.
