# Contributing

Contributions are welcome when they make the examples clearer, safer or easier to integrate.

## Good contributions

- New language examples.
- Better error handling.
- More complete filter examples.
- Framework-specific backend examples.
- AI-agent integration examples.
- Documentation fixes.

## Rules

- Do not commit API keys.
- Keep examples small and easy to copy.
- Prefer server-side examples when an API key is required.
- Use `X-API-Key` for authentication.
- Keep endpoint paths aligned with the official documentation.
