# Repository Summary

Apibara Vehicle Auction API Examples is the official example repository for integrating with Apibara Vehicle Auction Data API.

The API provides structured JSON access to supported Copart and IAAI auction vehicle data including VIN records, lot details, photos, prices, auction status, sale history, filters, locations, related vehicles and shipping prices.

2. llms.txt
3. llms-full.txt
